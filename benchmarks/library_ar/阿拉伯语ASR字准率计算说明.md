# 阿拉伯语 ASR 预处理与字/词准确率计算说明

## 1. 脚本用途

脚本 `asr_char_accuracy.py` 用于读取 `.xlsx` 中的阿拉伯语标注和一个或多个 ASR 批跑结果，统一完成：

1. 自动选择数据最完整的工作表。
2. 自动识别“标注”和“测试结果”列。
3. 对标注与识别结果执行完全相同的阿拉伯语文本归一化。
4. 基于 Levenshtein 编辑距离计算 CER、字准确率、WER 和词准确率。
5. 可选校验同目录 WAV 的编号、格式和时长。
6. 可选导出汇总 JSON 和逐条 CSV，便于定位差样本。

脚本只读取原始 Excel 和 WAV，不会修改源文件，也不依赖 `openpyxl` 等第三方包。

## 2. 快速使用

### 2.1 环境要求

- Python 3.10 或更高版本。
- 无需安装额外依赖。

先运行内置自检：

```powershell
python .\tools\asr_char_accuracy.py --self-test
```

### 2.2 计算本次 200 条数据

在项目根目录执行：

```powershell
python .\tools\asr_char_accuracy.py `
  ".\16k16bit单声道\Omani Accent Recording Text for ASR Test.xlsx" `
  --audio-dir ".\16k16bit单声道" `
  --split 100 `
  --output-json ".\output\oab_asr_accuracy_combined_summary.json" `
  --output-csv ".\output\oab_asr_accuracy_combined_details.csv"
```

脚本会自动选择有效标注最多的工作表。本文件中会选择 `Roqaya` 的 200 条数据，不会把 `mohamed` 中重复的 101–200 号再计算一次。

如果需要明确指定工作表：

```powershell
python .\tools\asr_char_accuracy.py `
  ".\16k16bit单声道\Omani Accent Recording Text for ASR Test.xlsx" `
  --sheet "Roqaya" `
  --split 100
```

### 2.3 指定结果列

默认会选取表头中所有包含“测试结果”的列。如果其他 Excel 使用了不同表头，可重复传入 `--hyp-header`：

```powershell
python .\tools\asr_char_accuracy.py ".\input.xlsx" `
  --reference-header "人工标注" `
  --hyp-header "第一次批跑" `
  --hyp-header "第二次批跑"
```

## 3. 计算口径

### 3.1 字符级公式

对每条标注和识别结果做归一化后，使用 Levenshtein 最短编辑距离对齐，得到：

- `S`：替换字符数。
- `D`：删除字符数，即标注中存在、识别结果中缺失。
- `I`：插入字符数，即识别结果中多出来的字符。
- `N`：归一化后标注字符总数。

整体指标使用微平均，即先汇总全部字符，再计算：

```text
CER = (S + D + I) / N
字准确率 = 1 - CER
```

例如 200 条样本会先累加 200 条的 `S/D/I/N`，而不是简单平均 200 个句子的准确率。这样短句不会和长句拥有相同权重，更适合作为批跑整体指标。

空识别结果不会被排除：该条标注的全部字符都会计为删除错误。字准确率理论上可能因大量插入而小于 0，脚本不会人为截断到 0。

### 3.2 词级公式

词级指标使用归一化后的空格分词结果进行 Levenshtein 对齐：

- `Sw`：替换词数。
- `Dw`：删除词数。
- `Iw`：插入词数。
- `M`：归一化后标注词数。

```text
WER = (Sw + Dw + Iw) / M
词准确率 = 1 - WER
```

词级指标同样使用全量微平均，不是逐句词准确率的简单平均。标点只作为分词边界，不作为词参与计算；数字等价口径会把完整数字短语统一成一个 MSA spelling 词元。

### 3.3 单一组合归一化口径

脚本只输出一个 `combined` 口径，依次执行基础归一化和数字归一化，不再提供两套可选结果。

处理流程：

1. Unicode `NFKC` 归一化。
2. 阿拉伯数字、波斯数字统一转成 ASCII 数字。
3. 删除阿拉伯语变音符号、古兰经标记、Tatweel 和不可见控制字符。
4. 统一常见字形：
   - `أ / إ / آ / ٱ → ا`
   - `ى → ي`
   - `ؤ → و`
   - `ئ → ي`
   - `ة → ه`
5. 删除无意义标点；字符级删除空格，词级保留统一后的词边界。
6. 将完整数字短语解析成一个整数值，再转换为固定的 MSA spelling 单词元。

示例：

| 标注写法 | ASR 写法 | 词级归一化后 |
|---|---|---|
| `خمسين` | `50` | `<NUM:خمسون>` |
| `ألف وخمسمية` | `1500` | `<NUM:ألف_وخمسمائة>` |
| `خمسة وعشرين` | `25` | `<NUM:خمسة_وعشرون>` |
| `بخمسين` | `ب 50` | `ب <NUM:خمسون>` |
| `سبعمية` | `700` | `<NUM:سبعمائة>` |

词级计算将整个 `<NUM:...>` 视为一个词元，因此 `1500` 不再拆成 `1000 + 500`。字符级计算则去掉词元包装和空格，使用完整 MSA spelling 参与 CER。

解析过程保留完整数值，所以 `<NUM:ألف_وخمسمائة>` 与 `<NUM:مليون_وخمسمائة>` 不会碰撞；只有数值完全相同的数字写法和数字词写法才会等价。

这套 `combined` 结果是唯一验收口径。如果数字金额本身是核心业务字段，仍建议另做“金额实体准确率”，不能只依赖整体 CER/WER。

## 4. Excel 读取和行号逻辑

脚本直接读取 `.xlsx` 内部 OOXML，不依赖 Excel 软件。

默认字段规则：

- 文件名列：`文件名称`
- 标注列：`标注`
- 结果列：表头包含 `测试结果`
- 表头行：第 1 行

工作表未指定时，脚本会：

1. 找出包含“标注”表头的工作表。
2. 统计每个工作表的非空标注数量。
3. 选择有效标注最多的工作表。

如果文件名列为空，脚本使用“当前 Excel 行号减表头行号”作为记录编号。本次文件中 Excel 第 2–201 行因此对应录音 1–200。

## 5. 输出内容

### 5.1 控制台

控制台输出包括：

- 实际使用的工作表和列。
- 每次批跑的字准确率、CER、有效输出数。
- 每次批跑的词准确率和 WER。
- 指定 `--split` 后的分段准确率。
- 空结果编号。
- 识别结果与标注的总长度比。
- 输出长度不足标注一半的条数。
- WAV 数量、采样率、位深、声道、压缩类型和总时长。

### 5.2 汇总 JSON

`--output-json` 保存机器可读的汇总结果，包括：

- 整体和分段指标。
- `S/D/I/N` 原始计数。
- 最差的 10 条记录。
- 空结果编号。
- 音频完整性检查。

### 5.3 逐条 CSV

`--output-csv` 保存每条记录的：

- 原始标注和原始识别结果。
- 归一化后的比较文本。
- 替换、删除、插入和总错误数。
- 单条 CER 和字准确率。
- 单条 WER 和词准确率。
- 是否为空结果。
- 输出长度是否不足标注一半。

CSV 使用 `UTF-8 with BOM`，可直接用 Excel 打开并正确显示中文和阿拉伯语。

使用统一 `combined` 口径、完整 200 条数据和 `--split 100`，预期关键结果如下：

| 批跑 | 字准确率 | CER | 词准确率 | WER |
|---|---:|---:|---:|---:|
| max_delay=0.7 | 94.26% | 5.74% | 85.58% | 14.42% |
| max_delay=2、volume_threshold=3.4 | 65.78% | 34.22% | 55.71% | 44.29% |

`combined` 分段预期：

| 分段 | 第一次批跑字准确率 | 第二次批跑字准确率 |
|---|---:|---:|
| 1–100 | 95.24% | 93.57% |
| 101–200 | 93.22% | 36.18% |

如果脚本版本、输入 Excel 和参数均未变化，但结果与上述数值明显不同，应优先检查：

1. 是否选错工作表或重复计算了 `mohamed`。
2. 是否漏算了第二批的空结果。
3. 是否改动了数字词字典或字形归一化规则。
4. 是否把逐句准确率做了简单平均，而不是使用微平均。

## 7. 参数速查

| 参数 | 说明 |
|---|---|

| `--sheet` | 指定工作表；默认自动选择 |
| `--header-row` | 表头行号，默认 1 |

## 8. 已知边界

1. 当前数字词表覆盖本批阿曼阿拉伯语数据中的常见整数表达，不是通用阿拉伯语数学解析器。
2. MSA spelling 使用固定主格形式以保证可重复计算，不根据上下文处理性别、格位和双数屈折变化。
3. 方言同义词和语义等价词不会自动视为相同，例如两个意思接近但拼写不同的词仍会产生字符错误。
4. 脚本读取的是 Excel 单元格中已保存的值，不负责重新计算公式。
5. 当前只支持 `.xlsx`，不支持旧版二进制 `.xls`。
6. CER/WER 反映整体转写质量；姓名、金额、账号等关键实体仍建议增加独立的完全匹配指标。
