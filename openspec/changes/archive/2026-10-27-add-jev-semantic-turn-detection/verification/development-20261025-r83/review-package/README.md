# r83阶段审核包

review-inputs.tar.gz包含当前源码、冻结原型、规格/决定、实际自测摘要及白名单证据。snapshot.json逐文件SHA-256，package-check.json记录包SHA与核验结果。共享工作区其他代码仅作为运行依赖上下文，不表示本Change拥有全部改动。

不是最终验收：RTC源端E2E、完整真实六模型、设备/默认采用及完整B仍有未关闭范围。评审应给BLOCKED或证据不足而非降低验收契约。不要运行付费探针、旧有限RTC诊断、外部服务或生产命令。

不含.env、数据库、真实客户素材、能力URL原始日志或录音。可使用既有锁定环境执行离线测试；裸机依赖安装/部署Python3.11未验证。包内记录是冻结时点，后续评审及包复核写在外层，避免篡改已审快照。
