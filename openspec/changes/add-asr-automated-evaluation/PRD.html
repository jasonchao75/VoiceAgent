一、概述

1.1 背景

项目交付缺少足够的巡检话术师，无法持续、规模化地从历史对话中发现 ASR 识别问题；发现的问题也缺少统一标签、音频证据、标注文本和来源信息，难以复用为模型评测数据。系统需以 AI 处理大批量筛选和证据归纳，以人工复核处理不确定样本。

1.2 产品目标

目标可验证结果
降低人工巡检范围人工仅处理第二轮无法可靠判断的 Case，而非全量用户句子
形成可追溯结论每条结论可追溯至批次、上下文版本、完整对话、事件、线上转写、评测 ASR 结果和录音
沉淀 Benchmark明确结论的 Good/Bad Case 以 AI 标注或人工标注来源进入 Library
支持交付决策报告提供问题分布和线上 ASR 表现观察，不将对照 ASR 结果误当成供应商准确率

1.3 目标用户与权限

角色核心诉求本期权限
项目交付/产品负责人发起评测、掌握进度、查看报告、管理配置查看全部批次；维护标签、上下文、资源、Prompt 与成本；可提前结束复核
人工复核人员快速复听并确认标注与负责人共用权限；本期不做任务领取和多人锁定
ASR/评测人员使用标准样本做后续模型对比查看和批量下载 Benchmark

1.4 名词说明

名词定义
线上转写生产流式 ASR 已产生的历史文本；页面不假设或展示其具体供应商
评测 ASR用于历史完整通话文件异步转写的 Soniox、Speechmatics、ElevenLabs 等资源
第一轮 LLM从历史对话中筛选可能改变业务含义的用户句子
第二轮 LLM综合线上转写、评测 ASR、上下文和标签字典完成证据判定与归类
Case以一个用户事件为最小单位的评测对象
Benchmark Library包含录音、历史文本、标注文本、语种、标签、来源和追溯信息的样本库

二、范围与原则

2.1 本期范围

  • 评测批次、新建评测、数据包校验和批次进度。
  • 全局场景标签、质检上下文、两轮完整 System Prompt、异步 ASR 能力、API Key、LLM 连接和成本配置。
  • 两轮 LLM、多异步 ASR、人工复核、最终报告和 Benchmark Library。
  • 中英文界面；中文模式对历史对话提供“英文/阿文原文 + 中文释义”。

2.2 暂不纳入

  • TTS、LLM 或端到端对话质量评测。
  • 线上流式 ASR 的接入、切换与生产配置修改。
  • 自动执行 ASR 调优、自动替换生产供应商、自动生成模型选型结论。
  • 多人领取、排他锁、复杂 RBAC 与跨组织数据隔离。

2.3 核心原则

原则要求
无预设真值线上转写和任一家评测 ASR 结果都只是证据
人工兜底证据不足时必须进入人工复核，不允许强行生成 Ground Truth
全程可追溯模型、Prompt、价格、标签、上下文均按批次冻结版本
资源隔离ASR API Key 集中管理；异步 Endpoint 配置在具体异步 ASR 能力中；LLM Base URL 保留在连接配置
所见即所得两轮完整 System Prompt 均可查看和编辑，不在代码中隐藏业务规则
双语一致英文模式无中文 UI；中文模式尽量中文化，但厂商、模型 ID、原始转写和真实 Prompt 不被界面语言自动改写

三、产品整体流程

3.1 准备工作

管理员先维护全局标签、质检上下文、两轮 Prompt、异步 ASR Endpoint、供应商 API Key、两轮 LLM 连接及价格。新建批次时可覆盖本批次使用的异步 ASR 与两轮 LLM，覆盖值仅影响该批次快照。

3.2 自动化评测主流程

选择上下文与资源→上传并校验三类数据→第一轮筛选疑点与同对话 Good 池→每通多 ASR 异步转写一次→第二轮证据判定与 1:1 Good 补足→人工复核并最终再平衡→冻结最终报告→写入 Benchmark

3.3 批次状态

校验中→运行中→待人工复核→已完成

任一外部资源失败进入“部分失败”；达到成本上限进入“已暂停”；负责人可提前结束复核并生成“部分覆盖”的最终报告。

3.4 输入与关联

目录内容格式用途
conversation_history/每通一份完整历史对话Excel两轮 LLM、事件时间与线上转写
record/机器人 + 用户完整通话MP3评测 ASR；对话明细固定播放器
user_record/纯用户音频WAV人工复核和 Benchmark 音频

每通数据分别使用 conversation_history/{conversation_id}.xlsx、record/{conversation_id}.mp3、user_record/{conversation_id}.wav，以完整 conversation ID 一对一关联。必须读取实际音频属性，不能只按扩展名判断。缺失、重复或无法解析时阻止开始评测，并提供问题清单与修复上传入口。
