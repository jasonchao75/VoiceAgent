# 历史 Gate 2 一页纸审核 — ASR 自动化评测

状态：历史记录；其内容现归入 Engineering Checkpoint A，不代表当前 User Gate 2，也不再进入旧 Gate 3
日期：2026-09-16

## 本轮审核目标

本轮主要审核产品结构、视觉方向和固定测试数据下的交互。唯一提前接入的真实能力是用户主动点击的 LLM 模型诊断：它复用现有接口并可能产生极少量费用；不包含真实批跑 ASR/LLM、Benchmark 数据写入或评测连接持久化。

## 当前可审核内容

- Evaluation 产品入口、评测批次列表和五阶段批次详情。
- 逐通 ZIP 数据结构说明、校验/修复入口和批次资源版本冻结。
- 人工复核：统一回听区间、历史转写与当前建议就近对比、各厂商候选平级展示，以及明确的 Good、Bad、听不清操作。
- 仅从评测批次进入的初步/最终报告，包含评测漏斗、Case 标签分布、AI 建议标签名称与描述、线上 Production ASR 问题汇总、30 条完整疑点 Case 和对话证据抽屉；确认创建时名称与描述一并写入全局标签并批量移动关联 Case；Case 明细可按场景标签筛选并显示命中数/总数，试听可就地展开播放/暂停、继续和可拖动进度；Soniox、Speechmatics、ElevenLabs 仅作为下游评测证据。
- Benchmark 每页 20 条、跨页保留选择、样本详情、“下载已选”与覆盖所有分页的“下载全部筛选结果”；ZIP 根目录为 `benchmark.csv`，WAV 按语种与主场景标签两级分组。
- 数据化场景标签支持新建、编辑新版本和删除；删除后不再用于新批次，但历史引用快照保留。质检上下文的“新建/编辑新版本”可打开完整表单，预填利雅得银行业务目标、流程、术语、规则和风险；保存只生成新版本。
- 第一轮/第二轮完整 Prompt 已按历史离线任务整理为中文上线初始数据：以通用参考词典集合代替分行专属变量，保留事件级候选与 segment 证据、Good/Bad/人工复核、双语建议标签和无置信度阈值规则。
- 质检配置新增“参考词典”：可创建/编辑版本化通用词典，并由上下文勾选关联。上下文弹窗就近展示五类运行时输入的来源及批次冻结关系。
- 两轮固定 Prompt 默认只读，通过明确按钮进入编辑；模板保留每个 Session 的变量插槽。上下文列表和编辑表单可切换预览两轮模板与成品 Prompt，并通过字段映射标记对应位置、展开关联词典全部 entries。
- 成本配置从服务端模型目录读取 OpenAI/Gemini 型号，包含 Gemini 3.8 Flash；“实测模型”可复用同厂商、同 Base URL 的已有 Bot 加密 Key 临时测试所选目录型号，展示脱敏诊断 ID 和首 Token 耗时，且不改写价格或原 Bot。
- 资源连接页的 Soniox、Speechmatics、ElevenLabs 可直接触发连接检查并与异步能力卡片同步状态；Gemini、GPT、Qwen、DeepSeek 复用既有 LLM 诊断接口，并在当前卡片就近展示测试中、成功或失败原因。
- 中英文页面框架；英文人工复核上下文中没有中文测试文案残留。

## 固定数据中的产品口径

| 产品规则 | Gate 2 页面体现 |
|---|---|
| 疑似错误占比分子 | 显示 `24 / 441 = 5.4%`，不会显示 `30 / 441` |
| 历史 30 个疑点 | 明确标注为固定回归数据，不是线上结果目标 |
| ASR 调用范围 | 第三阶段明确每家厂商每通对话只转写一次 |
| Good 平衡 | 结果节点同时显示疑点复判 Good 和额外 Good，补齐至与 Bad 1:1 |
| 人工复核 | Good 保留历史转写；Bad 必须提供正确文本；听不清直接排除 |
| 置信度 | 第二轮 Prompt 明确不输出、不依赖置信度进行分流 |
